# Pocket Dragons · The Choosing

Open `index.html` directly, or serve this folder as a static site. `Start-Game.cmd` is not needed for the browser version; it can be opened from any local static server.

This prototype has eight choices drawn from a branching graph of thirteen scenes and sixteen egg affinities. Each choice routes the player to a different next scene while contributing weighted resonance to one or more egg types. Several routes converge on different kinds of emotional tests, so the same step can feel different depending on what the player did earlier. The reveal ranks the top three and shows each as a percentage of total resonance. The full journey can be replayed with Restart.

Included art assets are from the supplied Pocket Dragons folder. The two supplied teaser videos are bundled for later use in an intro or trailer panel; the current playtest keeps the choosing uninterrupted.
